# AllItems

**AllItems** is a comprehensive collection challenge where players work individually or in teams to discover and collect every item, biome, mob, structure, and advancement in Minecraft.

> ⚠️ **Note:** *AllItems is currently in development and not fully supported.*

---

## ✨ Features & Settings

- **Team & Individual Modes**: Play cooperatively in teams or competitively as individuals.
- **Category Selection**: Choose which categories to collect (Items, Biomes, Mobs, Structures, Advancements).
- **Chain Mode**: Require objectives to be completed in a fixed order.
- **Progress Tracking & Leaderboards**: View progress and missing items via in-game menus.

---

## 📋 Commands

| Command                | Description                                        |
|:-----------------------|:---------------------------------------------------|
| `/allitemsprogress`    | View current collection progress and missing items |
| `/allitemsleaderboard` | Display the AllItems leaderboard                   |
| `/allitemssettings`    | Open the AllItems configuration GUI                |
