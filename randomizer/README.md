# Randomizer

**Randomizer** randomizes Minecraft drops and loot tables.

---

## ✨ Features & Settings

- **Block Drops**: Randomize item drops when breaking blocks.
- **Mob Drops**: Randomize item drops when killing mobs.
- **Chest Loot**: Randomize chest loot table contents.
- **Shared Mappings**: Choose whether all players share the same drop mappings or get unique mappings.

---

## ⚙️ Settings Menu

Access Randomizer settings via `/settings` in-game to toggle:
- **Block Drops**: Enable or disable block drop randomization.
- **Mob Drops**: Enable or disable mob drop randomization.
- **Chest Loot**: Enable or disable chest loot randomization.
- **Shared Mappings**: Synchronize mappings across all players.
